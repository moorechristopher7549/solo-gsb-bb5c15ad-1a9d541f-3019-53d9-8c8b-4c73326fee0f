# 博物馆单张展签排版工具（Museum Label Typesetter）

一个用于排版**单张**博物馆展签的 Web 工具：输入标题、中文说明文字、可选的**英文译文**
与展签物理尺寸（毫米），浏览器实时预览，并可直接打印或导出为与预览**同换行、同物理尺寸**的 PDF。

- 填写英文译文即进入**中英对照双栏模式**：标题横跨整签，中文原文与译文左右并列；译文留空保持单栏
- 可输入**修订稿**（≤300 字）生成**增删对照**：按 Unicode 字符最短对齐标出新增/删除片段，
  原稿与修订稿分别排版，任选一版作为成品预览与打印（差异标记不进入打印）
- 后端：Node.js + Express（仅提供静态页面）
- 前端：原生 JavaScript / CSS，无构建步骤、无前端框架
- 排版算法：按 Canvas **实际字宽**逐字/逐词测量 + 动态规划断行
- 无数据库、无第三方账号、无外部 API

## 一条命令启动（Docker Compose）

```bash
docker compose up --build
```

然后浏览器打开：

```
http://localhost:3000
```

首次启动会在容器内自动执行 `npm install`（依赖随启动安装，不预装在镜像中），稍等数秒即可。

> 如果本机使用的是独立 `docker`（无 Compose 子命令）：
>
> ```bash
> docker build -t museum-label-typesetter .
> docker run --rm -p 3000:3000 museum-label-typesetter
> ```

## 不用 Docker 的本地运行方式

需要 Node.js ≥ 18。

```bash
npm install        # 安装唯一运行时依赖 express
npm start
```

访问 http://localhost:3000 。

## 必要配置（环境变量）

| 变量 | 默认值 | 说明 |
|---|---|---|
| `PORT` | `3000` | 服务监听端口。改端口：宿主机侧改 `docker-compose.yml` 的 `"3000:3000"` 左侧；容器内监听改环境变量 `PORT` 并同步右侧。 |
| `HOST` | `0.0.0.0` | 监听地址，容器内保持默认即可。 |

例如用本机 8080 端口：

```bash
PORT=8080 npm start                     # 本地直跑
docker run --rm -p 8080:3000 museum-label-typesetter   # Docker
```

## 使用方法

1. 左侧输入**标题**与**中文说明文字**（正文内回车可分段；中文里可直接夹 English 单词）。
2. 如需中英对照，在**英文译文**框填写译文（同样支持回车分段）：
   - **填写译文** → 双栏模式：标题横跨整签，中文原文与译文在正文区左右并列，栏间距固定 6mm；
   - **译文留空（或仅空白字符）** → 保持现有单栏排版。
3. 如需修订对照，在**修订稿**框输入修订后的中文正文（不超过 300 字）：
   - 对照区按 Unicode 字符求**最短增删对齐**（同代价时固定保留原文较早字符），
     以删除线标出删除片段、底色标出新增片段；
   - 原稿与修订稿分别沿用当前尺寸与英文译文运行同一排版，
     对照区下方列出两版的正文字号、中文行数与能否容纳（含变化对比）；
   - 在**成品版本**中选择一版：预览与打印仅输出该版，差异标记不进入打印；
     所选版排不下时对照保留、提示超宽或超高并禁用打印；
   - **修订稿留空（或仅空白字符）** → 不进入对照模式，行为与之前完全一致。
4. 输入展签**宽度 / 高度（毫米）**，合法范围 30–999mm × 20–999mm，内边距固定 8mm。
5. 右侧实时预览（屏幕上会自动缩放以适应窗口，仅为显示效果）。
6. 点击「打印 / 导出 PDF」，在系统打印对话框中选择打印机或「另存为 PDF」。
   纸张尺寸会被自动设为展签的毫米尺寸，**边距请选择「无 / 默认」**，缩放保持 100%，
   即可得到与预览换行、字号、物理尺寸完全一致的成品。

## 排版规则

1. **实际字宽**：所有字符宽度由 Canvas `measureText` 按当前字号、字体实测（带缓存），
   不是按“汉字全角、英文半角”的假设估算。
2. **英文单词不可拆**：连续拉丁字母/数字（含词内连字符、撇号，如 `state-of-the-art`、`don't`）
   作为整体移动到下一行。
3. **标点避头尾（kinsoku）**：
   - 闭标点（`。，、！？：；）》】”’…—·` 等）不出现在行首；
   - 开标点（`（《【「“‘` 等）不留在行尾；
   - 成对破折号、省略号不会被拆到两行。
4. **全局最优断行**：动态规划枚举全部可行断点，在所有放得进行宽的排法中
   **最小化非末行空白宽度的平方和**（与 TeX 段落断行思想一致），使各非末行尽量均匀填满；
   代价相同时取行数更少的排法。
5. **字号选择**：正文字号从 **24px 向下枚举到 12px**，取能同时满足行宽与总高度的
   **最大整数**；标题字号固定为正文的 1.4 倍、加粗，并按同样规则折行。
   **双栏模式**下标题横跨整签（按内容全宽折行），中英两栏按扣除 6mm 栏间距后
   **平分得到的实际栏宽各自独立断行**；字号为两栏**共享**——枚举两栏在该字号下
   都能排下（行宽）且总高度（标题 + 较高一栏）不超签高的最大字号。
6. **装不下即报错**：若 12px 仍超出高度，或存在在最小字号下都放不进行宽的内容
   （例如超长英文单词），预览区显示红色错误，且**绝不截断或压缩字号**，打印按钮禁用。
   错误信息会标明问题所在：
   - 超宽：指出是**中文原文栏**还是**英文译文栏**（或标题）及该栏实际栏宽；
   - 超高：指出**哪一栏较高**，并给出内容所需毫米数与可用毫米数。
7. **打印一致**：预览的断行结果由同一算法一次性算出并直接写入 DOM（预断行），
   预览与打印共用同一份断行结果与毫米尺寸；打印时沿用同样的行、同样的 px 字号与
   毫米容器；`@page` 尺寸在打印前被设置为标签宽×高，保证 1px = 1/96 英寸的物理换算一致。
8. **修订对照**：原稿与修订稿按 Unicode 码位做 LCS **最短增删对齐**（只允许插入/删除，
   一次替换计为一删一增）；回溯时同代价固定按「删除 > 匹配 > 插入」取舍，
   效果是被保留的总是原文中较早出现的字符，结果确定唯一；
   相邻的「增＋删」片段对固定按「删在前、增在后」展示（与常见 diff 一致）。
   两版共用当前标题、英文译文与标签尺寸分别排版；成品版本由用户选择，
   预览与单张打印只输出所选版，差异标记只出现在左侧面板对照区。

```

    ├── index.html          # 单页界面
    ├── css/style.css       # 界面样式 + 毫米级展签 + 修订对照标记 + 打印样式

```

## 说明与限制

- 本工具面向**单张展签**：一个页面对应一张标签，不做多标签拼版。
- 双栏模式仅由**英文译文是否填写**控制：标题不随译文翻译，始终横跨整签；
  两栏共用同一正文字号与行高，不各自缩放；栏间距固定 6mm，暂不提供可调分隔线。
- 修订稿限 **300 字**（按 Unicode 码位计，输入框已限制长度）；对照的增删标记只出现在
  左侧面板对照区，展签预览与打印始终为所选版本的干净排版；
  所选成品版排不下时，对照与两版结论保留显示，预览区标明超宽/超高，打印按钮禁用。
- 对齐方式为左对齐（展签常见排版），不做两端对齐拉伸字距。
- 字体使用浏览器/系统自带的宋体/衬线字体族，无需联网下载字体；
  不同系统的字宽可能有细微差别，断行会在打开页面的那台机器上按其可用字体实测计算，
  因此请在实际打印的机器上进行最终预览确认。
- 全部计算在本地浏览器完成，不向任何外部服务发送内容。
